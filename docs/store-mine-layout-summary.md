# 门店页「我的」排版优化：总结文档

完成日期：2026-10-11。对应落地文档 `store-mine-layout-plan.md`。

## 一、改动前的问题

门店页 `mine` 视图是四个角色中唯一的异类。供应商、采购、财务均采用「身份卡 + 功能菜单列表 + 退出」的组合，门店页则是「身份 + 收货信息 section + 三个纵向按钮堆叠」，其中：

- 「刷新门店资料」是动作、「门店资料」是跳转去向，二者并列于同一按钮列表，无法区分
- 收货信息以整块 section 呈现，未纳入菜单体系
- 「账户与账单」入口位于第 92 行独立的 `wx:if` 块，游离在 mine 主区块之外
- 退出登录与常规操作同级，仅靠底色区分层级

具体动作：

- **O1** 收货信息并入功能菜单，主文案「收货信息」，副说明显示联系人与地址
- **O2**「账户与账单」入口移入 mine 主区块，消除割裂
- **O3**「刷新门店资料」移出菜单，改为菜单下方独立次要按钮，保留 `loading` 态
- **O4** 退出登录改用 `account-logout` 独立成块，与其余三角色一致

## 三、保留项

`components/test-context` 挂在 mine 视图上是测试工作台入口，五个角色页面均如此，且为文档流内条块而非浮层。本轮重排保留了它（仍在 wxml 首行），否则测试角色切换会失效。

## 四、顺带修正

**`pages/store/index.wxss` 未 import `styles/workspace.wxss`。** 本轮改用 `.account-menu` 系列样式，若直接引用会完全不生效——该文件是按需 import 的，只有 purchaser、supplier、region 三个页面引入了。已在 store 页首行补上 `@import`。

**清理失效样式**：`.logout-button` 在改用 `account-logout` 后已无引用，删除定义。`.delivery-info` 经确认仍用于下货单确认页，保留。

## 五、改动范围

| 文件 | 改动 |
| --- | --- |
| `pages/store/index.wxml` | mine 区块重排，移除游离的账户入口块 |
| `pages/store/index.wxss` | 引入 workspace.wxss、新增 mine 样式、删除失效的 `.logout-button` |

## 七、后续

其余三个角色的 mine 视图尚未统一。供应商、采购已有菜单结构，仅需核对条目内容与层级；**财务页最单薄，目前只有身份卡与退出登录**，而 `pages/finance-accounts` 页面已存在却无入口，建议下一轮补齐财务账户入口与「本机提交记录」，使其与另外三角色对齐。
