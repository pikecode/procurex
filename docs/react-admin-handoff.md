## 入口与运行

- 默认后台：http://127.0.0.1:4174/，`npm start`。
- 后端：`PORT=3114 npm run start:api`；数据库、worker、静态部署步骤见README。
- 原后台：`npm run start:web:legacy`。仅切换入口，数据库共享，不回滚账务。
- 管理员命令诊断：`/commands`；财务、门店、采购及供应商无此管理入口。
- 不在文档记录密码、AccessKey或微信密钥。沿用本地已配置账号。

## 已知限制

- 命令列表取最近100条，每页默认10条是前端分页，不是全量历史审计搜索。
- 原子价格关闭最终由服务端证明，界面不具备任意解锁能力；复核不是重新执行订单，也不修改余额。
- 未知提交须使用原请求/原键恢复，不手工清除浏览器记录后重新提交。
- 首屏公共包仍有大于500KB构建警告；部分窄屏订单内嵌明细排版仍待用户验收，不作为新增主流程开发范围。
