## 本轮细化重点

1. 供应商少发与永久减量分开，缺货及收货差异均有可追溯待补来源。
2. 充值后，待采购订单由采购确认；已确认订单另有资金重校验入口，不重复拆单。
3. 销售价、供货价与字段权限在查询响应、导出和凭证中一致执行。
4. 原计价事实、可核销明细、账单和调整单分层；供应商总单与分店单不形成两笔应付。
5. 已结清差额保留原周期，负调整支持后续抵扣或线下返还，避免无法结束的财务记录。
6. 40项 SRS 验收逐一映射开发任务，另列并发、重试、精度、权限和恢复测试。

本轮可以按四份文档统一反馈修改意见。已确认的7组架构决策不重复询问；云资源、账号和期初数据等实施信息见开发计划末章，按阶段补齐。
