# 订货模板当前规则

最后更新：2026-10-11

本文是订货模板、供应商价格和门店结算周期的当前口径。历史开发日志和优化方案若与本文冲突，以本文及 `docs/requirements.md` 为准。

## 1. 门店与模板

- 一个门店同一时间只能绑定一个有效订货模板。
- 一个有效模板可以绑定多个门店；门店只能订购自己所绑定模板内的可订商品，没有有效模板不能新建下货单。
- 已被其他有效模板使用的门店在选择框中显示占用模板名称并禁用，不能在保存时自动抢占或转移。
- 模板归档后解除当前门店、商品和周期关联；历史订单及价格、结算快照不受影响。

## 2. 商品与供应商

- 模板从商品库添加商品；商品必须至少存在一个已启用且维护了有效供货价的供应商。
- 待添加商品可跨分类批量勾选。点击“加入已选并配置价格”后弹窗保持打开，切到已选商品并自动展开新增商品的价格配置。
- 已选商品的分类树只显示当前模板中实际有商品的分类及其父级；待添加商品显示完整分类树。
- 模板自动继承商品资料中符合条件的全部供应商，不在模板内重复新增或移除供应商。
- 一个商品可有多个供应商，必须设置一个首选供应商；首选用于采购分配优先级，不限制备用供应商。
- 供应商下架该商品后，不再参与新订货目录与分配；保留关联和已有订单。重新上架仍需商品启用、供应商可用及有效价格。

## 3. 三类价格

| 价格 | 维护位置 | 用途 |
|---|---|---|
| 商品价格 | 商品资料 | 参考和维护比对，不直接用于门店下货、订单计价或结算 |
| 供应商价格 | 商品与供应商关联 | 供货价格及采购成本；同一商品不同供应商可不同 |
| 销售价格 | 模板的商品 × 供应商 | 门店下货、订单计价及结算价格；每个供应商可分别设置 |

- 新增销售价格时默认取对应供应商价格，允许采购人员单独调整；初始化后不随供应商价格自动覆盖。
- 首选供应商用于下货单初始报价；采购确认前更换供应商时，只能选该下货单所用模板中该商品配置的可供货供应商，并重新读取目标供应商对应的销售价格和供应商价格。
- 正式订单保存实际供应商、销售价格、供应商价格和价格版本快照，商品价格不参与交易计价。
- 结算方式不改变价格定义；供应商账期结算也不强制销售价格等于供应商价格。
- 缺少有效供应商价格时不允许加入或保存模板，并明确提示具体商品和供应商。缺少有效销售价格时目标规则为阻止报价和确认，不能回退到公共价格。
- 销售金额 = 销售价格 × 销售单位数量；供应商金额 = 供应商价格 × 销售单位数量。采购单位需先按换算关系归一，所有界面价格及金额显示两位小数。
- 旧文档和现有界面中的“参考销售价”对应商品价格、“供货价”对应供应商价格、“门店销售价 / 模板销售价”对应销售价格；后续新增及调整统一使用本表名称，不新增第四种价格。

### 3.1 当前实现差异

- 采购确认小程序以商品名称、订货数量及单位为主，默认只显示一项销售金额；清单顶部“价格明细”开关默认关闭。开启后分别展示销售价格、供应商价格、销售金额、供应商金额及分组金额，来自下货单交易快照，不使用商品参考价格。各项显示两位小数，单价标明销售单位；更换供应商后重新加载快照及分组。其他页面的历史价格文案统一仍需按模块核对。
- 当前 `effective-price.ts` 在没有已生效模板销售价格时会回退到供应商公共价格。此行为不符合上述严格口径，收紧解析及相关回归待实施，本次文档更新不代表代码已修复。
- 订单详情展示交易快照，不能把当前模板编辑值无条件覆盖到历史单据；已有价格生效时间及重算规则继续适用。

## 4. 结算方式与周期

- 每个供应商只维护一种结算方式：储值、挂账、供应商账期结算或公司账期结算。
- 模板不覆盖供应商结算方式，门店下单时按实际供应商自动匹配，不由门店选择。
- 只有供应商账期结算和公司账期结算需要结算周期。
- 供应商资料维护默认结算周期；模板可按“门店 × 供应商”覆盖周期，模板值优先。
- 后台门店结算周期下拉直接显示实际选中值（现结、周结、半月结、月结），不展示“使用供应商默认”等实现术语。未建立覆盖时，界面选中供应商默认周期；选择与默认值相同的周期不保存冗余覆盖记录。
- 周结为自然周周一至周日；半月结为自然月 1—15 日和 16 日至月末；月结为自然月 1 日至月末，均按北京时间计算。

## 5. 保存与历史

- 商品、供应商优先级、各供应商门店销售价一次保存；结算周期独立配置和保存。
- 所有保存使用模板版本做并发校验，版本冲突时刷新后重试，不静默覆盖他人修改。
- 后续价格、供应商、周期调整不改写已生成订单的历史快照。

## 6. 当前界面

- 模板列表主要操作为“编辑”，商品配置、结算配置、复制、归档收进更多菜单。
- 商品配置主表保持单行展示；价格配置在商品展开区按供应商逐行维护。
- 操作列固定在右侧，金额统一显示两位小数，负毛利明确标红。
