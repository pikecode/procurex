## 手动验证

1. 微信开发者工具导入项目，确认程序中的 API 配置及开发测试的域名校验设置。
2. 门店账号登录，选择测试珍珠粉圆 10 袋，预览 120 元并提交。
3. 退出并登录采购账号，找到测试门店的新订单，确认采购。
4. 退出并登录供应商账号，对该订单全量发货，运费填 0。
5. 退出并登录门店账号，对待收货单全量确认收货。
6. 核对订单完成，储值余额扣减 120 元，预占释放。每次重复会新增真实测试单据并扣减测试余额。

## 脚本

`infra/deploy/seed-mini-test.mjs` 只创建独立测试数据，不删除业务数据。需要指定服务器数据库和 `CONFIRM_SERVER_TEST_DATA=procurex-mini-test`，重复创建会因唯一编码冲突而回滚；不用于重置已存在数据。

`node infra/deploy/check-mini-test.mjs` 读取私有账号文件，向服务器新增测试充值 1000 元及一张 120 元订单并完成收货。只应在需要新增测试单据时运行，不能作为无副作用健康检查。结果保存在 `.env.mini-test-result.json`。
