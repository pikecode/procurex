## 复现

构建并启动 API/Web，运行 `npm run web:test`、`npm run web:check`。浏览器脚本需 Playwright：`PLAYWRIGHT_MODULE_PATH` 可指向外部安装模块；`WORKSPACE_API_URL`/`WORKSPACE_WEB_URL` 选择本机服务，`CHROME_BIN` 指定浏览器，`WORKSPACE_BROWSER_WS` 支持隔离浏览器。本轮临时 Linux 浏览器容器不改变生产部署。

执行 `npm run web:capture-workspace`，唯一 PXWEB 前缀夹具结束必须清理通过。中断后的命名夹具可用 `node --env-file-if-exists=.env scripts/capture-web-workspace.mjs --cleanup-prefix=PXWEB<时间戳>` 清理；不能用于真实业务数据。

原生资料/改价：微信开发者工具打开`apps/miniprogram`，登录页API选择`http://127.0.0.1:3114/api/v1`。执行`npm run mini:capture-profile-prices`；截图服务不可用时`-- --without-screenshots`只验证功能，manifest必须明确NOT_VERIFIED。中断夹具仅可`-- --cleanup-prefix=PXNATIVE<时间戳>`清理；脚本不修改既有账号、密码或账户余额。
